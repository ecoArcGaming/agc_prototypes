# Test Data

## Summary
This folder contains different types of data that can be used for testing the pipeline. 

## Subfolder Description

### Audio/
This subfolder contains Ukranian mp3 audio clips generated using Google Translate and ElevenLabs (https://elevenlabs.io/text-to-speech/ukrainian). ElevenLabs provides a tool to convert Ukrainian text into lifelike speech. 

Below are sample audio files (all are in Ukranian): 
Audio/audio_0.mp3: "What's on the screen?" 
Audio/audio_1.mp3: "What should I do next?"
Audio/audio_2.mp3: "Are there any enemies nearby?"
Audio/audio_3.mp3: "How much health do I have left?"

### Screen/
This subfolders contains screenshots of gameplay.
